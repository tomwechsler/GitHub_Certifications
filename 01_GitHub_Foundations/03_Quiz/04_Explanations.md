## Question 1 – Domain 1: Introduction to Git and GitHub

**Which statement best describes the relationship between Git and GitHub?**

A. GitHub is a graphical interface that uses Git for version control. ✅  
B. Git is a cloud service that depends on GitHub to function. ❌  
C. Git and GitHub are identical tools with different names. ❌  

**Explanation:**

* **A is correct** because GitHub builds on Git by providing hosting, collaboration, and additional features.
* **B is incorrect** because Git works independently of GitHub and does not require the cloud.
* **C is incorrect** because Git is a tool, while GitHub is a platform.

## Question 2 – Domain 2: Working with GitHub Repositories

**What is the main advantage of using a `.gitignore` file?**

A. It improves repository performance by compressing files. ❌  
B. It prevents specified files from being tracked by Git. ✅  
C. It encrypts sensitive files automatically. ❌  

**Explanation:**

* **A is incorrect** because `.gitignore` does not affect performance or compression.
* **B is correct** because `.gitignore` tells Git which files should not be tracked or committed.
* **C is incorrect** because encryption is not handled by `.gitignore`.
