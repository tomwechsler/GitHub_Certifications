## Question 1 – Domain 1: Introduction to Git and GitHub

**What is the primary purpose of Git?**

A. Git is a distributed version control system that tracks changes in source code over time. ✅  
B. Git is a cloud-based platform used only for hosting and sharing code repositories. ❌  
C. Git is a project management tool designed to track tasks and deadlines. ❌  

**Explanation:**

* **A is correct** because Git allows developers to track changes, collaborate, and manage different versions of source code locally and remotely.
* **B is incorrect** because this description fits GitHub, not Git itself, which is a version control system.
* **C is incorrect** because Git does not provide task or deadline tracking features, which are part of project management tools.

## Question 2 – Domain 2: Working with GitHub Repositories

**What is a GitHub repository?**

A. A GitHub repository is a storage space that contains a project’s files, commit history, and configuration. ✅  
B. A GitHub repository is a user profile that displays activity and followers. ❌  
C. A GitHub repository is a communication tool used only for chatting with team members. ❌  

**Explanation:**

* **A is correct** because a repository stores all project files, their revision history, and related settings in one place.
* **B is incorrect** because a user profile represents an individual account, not a project or its files.
* **C is incorrect** because GitHub repositories are not chat tools, even though collaboration features exist within them.

## Question 3 – Domain 3: Collaboration Features

**What is the main purpose of a Pull Request on GitHub?**

A. A Pull Request is used to permanently delete a branch from a repository. ❌  
B. A Pull Request is used to notify GitHub administrators about security issues. ❌  
C. A Pull Request is used to propose changes, review code, and merge contributions into a branch. ✅  

**Explanation:**

* **A is incorrect** because deleting branches is a separate repository management action and not the purpose of a Pull Request.
* **B is incorrect** because security issues are typically reported using security advisories, not Pull Requests.
* **C is correct** because Pull Requests enable discussion, code review, and controlled merging of changes into a target branch.

## Question 4 – Domain 4: Modern Development

**How does GitHub Actions support modern software development practices?**

A. GitHub Actions replaces Git and removes the need for version control. ❌  
B. GitHub Actions provides automated workflows for building, testing, and deploying code. ✅  
C. GitHub Actions is only used for manual code reviews. ❌  

**Explanation:**

* **A is incorrect** because GitHub Actions works alongside Git and does not replace version control systems.
* **B is correct** because GitHub Actions enables continuous integration and continuous deployment (CI/CD) through automated workflows.
* **C is incorrect** because GitHub Actions focuses on automation, not manual review processes.

## Question 5 – Domain 5: Project Management

**Which GitHub feature is primarily used to track tasks, bugs, and feature requests?**

A. GitHub Issues are used to track tasks, bugs, and feature requests within a repository. ✅  
B. GitHub Commits are used to assign tasks and manage deadlines. ❌  
C. GitHub Forks are used to organize project work and responsibilities. ❌  

**Explanation:**

* **A is correct** because GitHub Issues provide a structured way to track work items, discussions, and progress within a project.
* **B is incorrect** because commits record code changes, not tasks or project planning information.
* **C is incorrect** because forks are copies of repositories and are not designed for task tracking.

## Question 8 – Bonus Question (Mixed Domains)

**Why is branching important in Git-based workflows?**

A. Branching allows developers to work on features or fixes independently without affecting the main codebase. ✅  
B. Branching permanently deletes old versions of the code. ❌  
C. Branching prevents collaboration between multiple developers. ❌  

**Explanation:**

* **A is correct** because branches enable isolated development and safer integration of changes.

## Question 9 – Domain 2: Working with GitHub Repositories

**What is the purpose of a fork in GitHub?**

A. A fork is used to permanently synchronize two repositories automatically. ❌  
B. A fork is a personal copy of a repository that allows independent development. ✅  
C. A fork is required to delete files from a repository. ❌  

**Explanation:**

* **A is incorrect** because forks do not automatically stay in sync with the original repository.
* **B is correct** because a fork creates an independent copy of a repository where changes can be made without affecting the original project.
* **C is incorrect** because deleting files does not require forking a repository.

## Question 10 – Domain 6: Privacy, Security, and Administration

**What is the main purpose of enabling two-factor authentication (2FA) on GitHub?**

A. Two-factor authentication improves repository performance and loading speed. ❌  
B. Two-factor authentication allows users to manage multiple accounts more easily. ❌  
C. Two-factor authentication adds an extra layer of security to protect user accounts from unauthorized access. ✅  

**Explanation:**

* **A is incorrect** because security features do not affect performance or speed.
* **B is incorrect** because 2FA is not designed for account organization or management.
* **C is correct** because 2FA requires an additional verification step, significantly reducing the risk of account compromise.
